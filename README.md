# K2-Project-Original

SPT(Single Player Tarkov) 4.1용 대우 K2 소총 모드입니다.

## 구성

- K2 소총과 전용 부품 11종을 추가합니다.
  - 상부, 총열, 핸드가드 3종(MITS 롱·클래식·유탄발사기용), 소염기, 개머리판 3종(기본·AR식·경량), 30발 탄창
  - K201 40mm 유탄발사기
- 모든 아이템은 피스키퍼가 판매합니다.
- 서버 모드(DLL) 하나와 Unity 에셋 번들로 되어 있습니다. 클라이언트 플러그인은 필요 없습니다.
- 동작은 AK-101을 바탕으로 K2에 맞게 고친 전용 동작을 씁니다.
  - 오른쪽 개머리판 접기
  - 왼쪽 조정간
  - 탄창을 곧게 넣기
  - 노리쇠 멈치로 장전

바뀐 내용은 [RELEASE_NOTES.md](RELEASE_NOTES.md)에 있습니다.

## 설치

1. 릴리즈의 `K2-Project-Original-<버전>.zip`을 받습니다.
2. 이전 버전이 있으면 `SPT_Runtime/user/mods/K2-Project-Original` 폴더를 지웁니다.
3. zip 안의 `SPT_Runtime` 폴더를 SPT 설치 폴더에 그대로 덮어 복사합니다.
4. 서버와 게임을 다시 켭니다.
