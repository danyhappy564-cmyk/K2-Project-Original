K2-Project-Original v1.0.0 — 대우 K2 소총 첫 정식 릴리즈 (K201 유탄발사기 추가, K2 전용 동작)

SPT 4.1용 대우 K2 소총 모드입니다. K2 소총과 전용 부품 11종을 피스키퍼가 팝니다.
서버 모드 하나라 따로 깔 플러그인은 없습니다.
테스트 빌드(0.6.1)를 받으셨던 분들은 가지고 있던 K2와 부품이 그대로 남습니다.

모드가 마음에 드셨다면 후원으로 응원해 주세요: https://buymeacoffee.com/real_feels

[구분선]

■ 들어 있는 것

- K2 소총 (기본 구성 'K2 표준')
- 상부, 총열, 소염기, 30발 탄창
- 핸드가드 3종: MITS 롱 / 클래식 / 유탄발사기용
- 개머리판 3종: 기본 / AR식 / 경량
- K201 40mm 유탄발사기

■ 테스트 빌드(0.6.1)에서 바뀐 것

1) K201 유탄발사기 추가
- 언제: 유탄발사기용 핸드가드(피스키퍼 1레벨)에 K201(피스키퍼 2레벨)을 달면 됩니다.
- 이제: K201에 달린 조준기(왼쪽 가늠자 + 가늠쇠)로 조준하고, 영점은 바닐라 M203과 같은 약 100m입니다. 가까운 거리에서는 탄이 조준점보다 조금 높게 떨어집니다.
- 테스트 중 "탄이 왼쪽 아래로 간다"는 문제가 있었는데, 유탄은 발사기가 향한 방향 그대로 날아가서 발사 방향을 조준기 선에 맞춰 고쳤습니다.
- 바닐라 M203이나 GP-25를 달면 개머리판을 접을 수 없지만, K201은 실총처럼 단 채로 접힙니다.
- 확인: 테스터 게임에서 장착, 발사, 장전 동작 확인했습니다.

2) 개머리판 접기가 실총처럼 오른쪽으로
- 언제: 0.6.1은 AK 동작을 그대로 써서 개머리판이 왼쪽으로 접혔고, 손이 개머리판을 뚫거나 허공에서 접히는 것처럼 보였습니다.
- 왜: 원래 AK용 동작이라 K2의 접히는 방향, 경첩 위치와 맞지 않았습니다.
- 이제: K2 경첩을 축으로 오른쪽으로 접힙니다. 왼손은 핸드가드를 잡고 있고, 오른손이 개머리판을 밀어서 접습니다(G36 접는 동작을 바탕으로 만듦). 접을 때 손이 덜덜 떨리던 것, 펼 때 팔이 꺾이던 것, 접고 나서 총이 툭 튀던 것도 고쳤습니다.
- 확인: 테스터 게임에서 확인했습니다.

3) 조정간 레버가 실제로 돌아감
- 언제: 0.6.1은 AK처럼 오른손이 오른쪽으로 가서 조정간을 만지는 시늉만 했고, 레버는 움직이지 않았습니다.
- 이제: 왼쪽 조정간 레버가 안전, 단발, 연발로 돌아가고 엄지로 돌립니다.
- 확인: 테스터 게임에서 확인했습니다.

4) 탄창이 곧게 들어가고 손에서 안 떨어짐
- 언제: 0.6.1은 AK처럼 탄창을 비스듬히 걸어 끼우면서 탄창이 총 몸을 뚫고 지나갔고, 손과 탄창이 떨어져 보였습니다.
- 이제: 탄창이 탄창 구멍으로 곧게 들어가고, 넣고 빼는 동안 왼손이 탄창을 쥐고 있습니다. 동작이 뚝뚝 끊겨 보이던 것도 부드럽게 바꿨습니다. 탄창 멈치도 AK 레버가 아니라 M16처럼 오른쪽 버튼이 눌립니다.
- 확인: 테스터 게임에서 확인했습니다.

5) 빈 탄창 장전이 숙련도에 따라 바뀜
- 이제: K2 전용 무기 숙련도가 새로 생깁니다(AK-74 계열과 같은 기준). 처음에는 오른손으로 장전손잡이를 당기고(약 1.6초), 숙련도가 오르면 M4처럼 왼손으로 노리쇠 멈치를 탁 쳐서 장전합니다(약 0.8초).
- 왜: 0.6.1에서는 K2가 숙련도 목록에 없어서 숙련도가 오르지 않았습니다.
- 확인: 멈치 치는 동작은 테스터 게임에서 확인했습니다. 숙련도가 올라 동작이 바뀌는 것은 아직 게임에서 확인 못 했습니다.

6) 기타
- 장전, 탄 넣기, 약실 확인 같은 동작에서 오른손이 K2 장전손잡이를 제대로 잡습니다.
- 약실에 든 탄이 총 옆으로 튀어나와 보이던 것을 고쳤습니다.
- 총을 살짝 올려서 조준선은 그대로 맞고, 검지가 방아쇠에 걸리게 했습니다.
- 앞손잡이 자리를 5.5cm 앞으로, 탄창 자리를 2.7cm 위로 옮겨 K2 전용이 아닌 탄창도 맞게 들어갑니다.

■ 아직 남은 것

- 조정간을 돌릴 때 엄지가 레버에 1cm쯤 겹쳐 보입니다.
- 총이 막혔을 때 고치는 동작 몇 개는 아직 AK 동작 그대로입니다.
- 접힌 개머리판의 경첩 핀이 흰색으로 보입니다.
- 멈치를 칠 때 처음 한순간 노리쇠가 뒤로 젖혀진 자리로 바뀝니다.
