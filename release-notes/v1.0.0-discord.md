## K2-Project-Original V 1.0.0

**- 대우 K2 소총 첫 정식 릴리즈: K201 유탄발사기 추가, K2 전용 동작**

■ 기능
- K2 소총 + 전용 부품 11종(핸드가드 3종, 개머리판 3종, K201 유탄발사기 등), 피스키퍼 판매
- 서버 모드 하나만 설치하면 됨(플러그인 없음)

■ 테스트 빌드(0.6.1)에서 바뀐 것
- K201 유탄발사기 추가 — K201 조준기로 조준, 영점 약 100m. 달아도 개머리판 접힘 (테스터 확인)
- 개머리판이 실총처럼 오른쪽으로 접힘 — 왼손은 핸드가드, 오른손이 밀어 접기. 손 떨림·팔 꺾임 고침 (테스터 확인)
- 조정간 레버가 실제로 돌아감 — 왼쪽 레버를 엄지로 (테스터 확인)
- 탄창이 곧게 들어가고 손에 쥔 채 넣고 뺌 — 총 몸 뚫던 것 고침, 멈치는 M16식 버튼 (테스터 확인)
- 빈 탄창 장전: 처음엔 장전손잡이 당기기, 숙련도 오르면 M4처럼 멈치 치기 — K2 전용 숙련도 추가 (멈치 동작 확인, 숙련도 전환은 미확인)
- 장전손잡이 잡는 손·약실 탄 위치·조준선·앞손잡이/탄창 자리 맞춤
